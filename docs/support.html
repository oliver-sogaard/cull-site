Something wrong? Say so from inside the app. Settings → Feedback. Say what happened and what you expected, and you read every word of the report before it goes anywhere.

A report contains no photograph and no thumbnail, and every file and folder path in it is reduced to its file extension. The one exception is a screenshot you add yourself, which can show your photographs. You can save the report as a file or send it by email instead.

Or write to support@cull.photography.

Your license

  • Where is my key? In the email CULL sent when the license was issued, with the subject "Your CULL Pro key". Lost it? Have it sent again.
  • A new computer. A key works on two computers at a time. Remove it on the old one (Settings → License → Remove license from this computer), then enter it on the new one. If the old computer is gone, enter the key on the new one and choose which computer to replace.
  • "This license is in use on other computers." Both seats are taken. Enter the key again and pick the computer to replace, or remove one from the computer that holds it.
  • "Pro is paused." The copy has not reached the license service for 30 days. Connect to the internet once and open Settings → License.
  • A subscription ending. Pro runs to the end of the paid period, then the copy returns to Free. Nothing is deleted, and your verdicts stay where they are.
  • Canceling a subscription. In CULL: Settings → License → Manage subscription.
  • Refunds. Within 14 days of a payment, write to support or ask Paddle, and it is refunded in full. The refund terms.

Installing

Windows shows "Windows protected your PC" the first time the installer opens, and a Mac says the app is damaged and can't be opened. Both are about the missing publisher certificate, which CULL does not carry on either system, not about the file. The install page shows the clicks past each, and how to check a download by its checksum.

If CULL will not start

The log file is called cull.log. On Windows it is in %LOCALAPPDATA%\dev.cull.app\logs, on a Mac in ~/Library/Logs/dev.cull.app. It contains no file names. Send it along.

Lightroom does not show the verdicts

  • Import the folder with Add, not Copy, so Lightroom reads the sidecars where they are.
  • If the folder is already in the catalog, select the photos and choose Metadata → Read Metadata from Files.
