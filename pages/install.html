Installing CULL

One download for Windows, one for Mac, both from the downloads page. The app updates itself from then on.

Windows

Download CULL-setup.exe and open it. The first time, Windows shows this:

The screen means the installer carries no publisher certificate. It does not mean anything was found in it. Windows shows it for any installer it has not seen many times before, and the updates CULL installs later do not show it.

Why it is not signed

CULL is made by one person, Oliver Søgaard-Andersen. A Windows signing certificate costs more each year than CULL earns, so the installer goes out unsigned. If that changes, the screen goes away on its own.

Check the download yourself

Each release lists the SHA-256 of both installers and a VirusTotal link, where seventy-odd antivirus engines report on that exact file. To compare the checksum, open PowerShell and run Get-FileHash ~\Downloads\CULL-setup.exe; the hash it prints should match the one on the downloads page.

Mac

Download CULL.dmg, open it, and drag CULL to Applications. CULL runs on Apple silicon Macs.

Until CULL is notarised by Apple, the first launch says the app could not be verified. Close that message, open System Settings → Privacy & Security, scroll down to the line that names CULL, click Open Anyway and confirm. From then on it opens like any app.

To check the download, open Terminal and run shasum -a 256 ~/Downloads/CULL.dmg and compare it with the downloads page.

Then

Open a folder of RAW files, or drop one on the window. Press Tab for the keys. Something wrong? Support.
